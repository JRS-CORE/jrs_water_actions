# jrs_water_actions

> JRS Core water actions - wash and drink in rivers and lakes

![RedM](https://img.shields.io/badge/RedM-cfx-b22222) ![Lua](https://img.shields.io/badge/Lua-5.4-2c2d72) ![License](https://img.shields.io/badge/license-GPL--3.0-blue) ![Version](https://img.shields.io/badge/version-1.0.0-informational)

## Requirements

Requires **jrs_core**, **jrs_inventory** and **oxmysql**.

## Install

1. Download this repository and put the `jrs_water_actions` folder in your server `resources` folder.
2. Add `ensure jrs_water_actions` to your `server.cfg` after `ensure jrs_core`.

The easiest way is to install the whole framework with the txAdmin recipe from the main repo.
